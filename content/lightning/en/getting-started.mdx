In the book, Alice buys a coffee from Bob's café with a phone wallet. Here you play every part. Your lab has four <Term id="node">nodes</Term> on <Term id="regtest" />: Alice and Dina run LND, Bob and Chan run c-lightning, and they are already linked in a line, Alice → Bob → Chan → Dina.

## Step 1: Start the lab

In a terminal (on Windows, inside WSL2):

```bash
git clone https://github.com/bitsacco/jifunze
cd jifunze/lab
./lab doctor     # checks Docker, memory, disk and port 7777
./lab up         # starts the nodes; the first run downloads about 2 GB
```

`./lab up` ends by printing a **pairing code** like `ABCD-EFGH-JKLM`. Paste it into the lab bar at the top of this page and press Connect. You should see six green chips: bitcoind and the four nodes.

<Callout type="warning" title="Why pair?">
The lab only answers this website, and only with your code. Another site you visit can't run commands on your laptop.
</Callout>

## Step 3: Alice pays

Copy Dina's `payment_request` into the next exercise, replacing `INVOICE`, and run it. The `--force` flag skips the "are you sure?" question.

<Exercise id="ch02-alice-pays" />

The table in the output shows the route: Alice → Bob → Chan → Dina, with a tiny fee for each hop. Payment status `SUCCEEDED` and a **preimage** mean Dina was paid: in lesson 8 you'll see why that secret is the receipt.
