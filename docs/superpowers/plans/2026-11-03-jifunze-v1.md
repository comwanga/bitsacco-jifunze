# Bitsacco Jifunze v1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A free, Kiswahili-first, offline-capable static Bitcoin learning site with two 8-lesson roadmaps (savers, builders), quizzes, on-device progress, a glossary and a library.

**Architecture:** Next.js App Router built with `output: 'export'` into plain files in `out/`. Lessons, roadmaps, quizzes and the glossary are files in `content/`, validated by a script in CI and compiled from MDX at build time. Client JavaScript is limited to small islands: the intro animation trigger, the language switch, progress ticks, the quiz, export/import and service-worker registration. After the build, a step adds per-page CSP hashes, checks links and checks the performance budget.

**Tech Stack:** Next.js 16, React 19, TypeScript 6, Tailwind CSS 4, `@mdx-js/mdx` + `remark-gfm` (build-time MDX), `gray-matter` (front matter), `zod` (schemas), Vitest (unit tests), ESLint 9 + `eslint-config-next`, a hand-written service worker, and nginx-unprivileged for the container.

**Spec:** `Bitsacco Jifunze — v1 Spec.md` (project root). Opening-scene design chosen in brainstorming: **B2 "Mbuyu"**, a baobab growing at sunrise. Mockup: `.superpowers/brainstorm/286-1793696969/content/seed-realistic.html`, card `s2`.

## Global Constraints

- Node `>=24.20.0 <25`, npm `>=12.0.2` (`engines`, same as bitsacco repo); `.nvmrc` = `24`.
- `.npmrc` is exactly: `allow-git=none`, `allow-remote=none`, `ignore-scripts=true`, `strict-peer-deps=true`.
- No secrets, no `.env`, no third-party scripts, no analytics, no cookies, no web fonts (system font stack; that's my call to save budget).
- Kiswahili (`sw`) is the default language. Every page has a language switch to the same page in the other language.
- Budget: first lesson page transferred **< 200 KB** (gzip); JavaScript per page **< 100 KB** compressed.
- MDX is compiled at build time from `content/` only, never from user input.
- Brand: teal `#0f766e` / `#14b8a6` (Bitsacco primary), orange `#ff5800` (Bitsacco accent), plus the sunrise palette from the B2 mockup. Bitsacco logo from `bitsacco/bitsacco` `public/logo.svg`. Never use Pull's name or logo.
- Licences: MIT for code (`LICENSE`), CC BY-SA 4.0 for `content/` (`content/LICENSE`). Lessons adapted from Pull credit pullos.dev + CC BY-SA 4.0 in `source` and `ATTRIBUTIONS.md`.
- No financial or investment advice in lessons: explain how things work, never what to buy.
- All dates in content are `YYYY-MM-DD`.
- Every animation honours `prefers-reduced-motion: reduce` (show the final frame).

## Review Focus

1. **A broken or foreign progress file is imported.** The import is rejected with a readable message in the current language and existing progress is untouched (tests in Task 4).
2. **`localStorage` is unavailable or full** (private mode, quota). Pages still work, quiz still checks answers, and the progress page says progress can't be saved on this device (tests in Task 4).
3. **A `translationPending` lesson is opened in the missing language.** The reader shows the existing language's body with a notice and doesn't 404. The roadmap shows it too (tests in Task 2).
4. **Offline: a lesson never opened before is requested.** The service worker returns the offline page in the URL's language, not a browser error. A lesson opened once loads offline, including client-side navigation (`?_rsc=` `.txt` payloads cached with `ignoreSearch`) (manual check in Task 8).
5. **Intro on a returning visit, with reduced motion, or with no JS.** The scene shows fully grown with no replay. A tap or key press skips the animation, and the CTA and branch links are clickable while it plays (test of `shouldPlayIntro` in Task 5).
