# Jifunze Blog (Makala) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a blog (Makala / Blog) of reviewed MDX posts, in either language, that lead readers into the curriculum, with labelled diagrams and a colleague-friendly pull-request workflow.

**Architecture:** Posts live in `content/blog/`. A JSON registry holds the shared metadata and one MDX file per written language holds the text, loaded and validated at build time like lessons. Two static routes, `/{lang}/blog/` and `/{lang}/blog/{slug}/`, are rendered by Next.js static export. The category filter and diagram markers are small client islands over complete server-rendered HTML.

**Tech Stack:** Next.js 16 static export, native HTML video, React 19, TypeScript, zod 4, gray-matter, @mdx-js/mdx, Vitest, Playwright and axe.

**Spec:** `docs/superpowers/specs/2026-11-26-blog-design.md`

## Global Constraints

- No Sanity, CMS, external content API, webhook or automatic publishing. No client-side content fetching. CSP unchanged (`lib/build/csp.ts`).
- Kiswahili label **Makala**, English **Blog**. Routes `/{lang}/blog/` and `/{lang}/blog/{slug}/` with trailing slashes.
- A post has a Kiswahili file, an English file or both. Every post is listed on both indexes. A post missing in the page language shows a language badge and opens in its own language with a one-line note, like lessons' `translationNotice`.
- Registry fields: `slug`, `category`, `author`, `publishedAt` (`YYYY-MM-DD`), optional `updatedAt` (≥ `publishedAt`), optional `featured`, optional `image` (`/images/blog/…`), and `relatedLessons` (1–4 `roadmap/slug`).
- Frontmatter per language: `title`, `description`, `imageAlt` (required when `image` is set) and optional `terms`.
- Images and diagram images are self-hosted under `public/images/blog/`, are `.webp`, `.jpg`, `.png` or `.svg`, and may be at most **400 KB**. Alt text is required.
- Posts may use `Term`, `Callout`, tables, `Diagram`/`Marker`, `Video` and `VideoLink`. `<Exercise>` is a validation error.
- `Video`: self-hosted MP4 under `public/videos/blog/`, at most **2 minutes** and **10 MB**. A poster image, WebVTT captions in the post's language and a title are required. `preload="none"`, `playsinline`, controls, no autoplay or loop. Never cached by the service worker.
- `VideoLink`: a plain link card (https `href` passing `checkUrl`), self-hosted poster, title, duration, and a visible "opens on <host>" line. No embedded third-party players.
- Reading time is `ceil(words / 200)`, minimum 1. Dates are formatted at build time from `YYYY-MM-DD` as UTC calendar dates.
- Categories: `explainers`, `guides`, `developments`, `case-studies`, `myths`, `community`, `terms` and `pathways`, with labels exactly as in the spec table. Chips appear only for categories that have posts.
- Featured: the newest `featured: true` post leads the index, otherwise the newest post. It isn't repeated in the recent list.
- Related posts: up to 3, same category first, then newest, excluding the post itself. Hidden when there are none.
- The homepage is unchanged. Header gets one item (Makala/Blog) and the footer gets one Resources link. The header must pass the existing 360 px tests.
- No new runtime dependencies.
- Commits: no `Co-Authored-By` trailer (owner preference). Work on branch `feat/blog`. Push, PR and merge only with owner authorization.

## Review Focus

1. **A post written in one language** must appear on both indexes with a badge and open with the note, never as a 404. This is pinned in Task 1 (loader) and Task 5 (render).
2. **A reader offline taps a video:** the poster and a one-line "needs a connection" note show, not a broken player. Blog images visited online still show offline. Pinned in Task 4 (render) and Task 7 (e2e).
3. **A diagram on a 360 px phone** must not scroll sideways, and an open explanation must not cover the image. Pinned in Task 7 (e2e).
4. **Without JavaScript**, every post and every diagram explanation must still be readable. Pinned in Tasks 5 and 7.
5. **Dates near midnight or in another timezone** must not shift a day (`2026-11-26` stays 26 November in both languages). Pinned in Task 1.
