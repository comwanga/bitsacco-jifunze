# Phase 1 UX Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Better browsing and lesson navigation for Jifunze: a browser test harness, a three-column lesson reader, a reorganised home page, a searchable catalogue, a richer roadmap page, and housekeeping fixes. No server.

**Architecture:** Everything stays inside the static export. The new server components render lists, tables of contents and cards from the existing loaders. New client islands are kept tiny: reading progress, catalogue filter, continue/resume links. They reuse `useProgress`. Heading ids come from an in-repo remark plugin shared with the table-of-contents extractor, so the anchors and links always agree.

**Tech Stack:** Next.js 16 static export, React 19, TypeScript, Tailwind 4, Vitest. New dev dependencies: `@playwright/test` 1.64.1 and `@axe-core/playwright` 4.14.0.

**Spec:** `docs/superpowers/specs/2026-11-03-phase-1-ux-design.md`

## Global Constraints

- Non-lab pages may grow by at most +3 KB gzip of JavaScript over the baseline (lesson 144.3, home 141.9, roadmap 142.1 KB); lab pages by at most +3 KB over 150.2 KB. Checked with `pageWeight` after each UI task.
- Axe must report no `serious` or `critical` violations on the home, roadmap, lesson, catalogue and glossary pages in both languages.
- Every new string goes in both `sw` and `en` in `lib/i18n.ts`.
- No new runtime dependencies.
- Reduced motion shows static states, and every feature works with the keyboard.
- Offline reading of previously opened lessons keeps working.
- Commits are signed, with no Co-Authored-By trailer. No pushing.

## Review Focus

1. **A heading text appears twice in a lesson, or contains Kiswahili letters, punctuation or inline code.** The ids must be unique and stable, and the table-of-contents links must jump to the right heading (Task 2 tests).
2. **A brand-new visitor with empty or unavailable storage.** No continue card, no broken Resume button, and the server-rendered HTML must match the first client render (Task 3 tests).
3. **The catalogue with JavaScript off, or a search with no results.** The full list renders server-side, and an empty result shows a clear message, not a blank area (Task 4).
4. **A lesson that has a quiz and lab exercises.** A passed quiz must **not** mark it complete; only the labs do. A quiz-only lesson is marked complete at ≥75% (Task 6 tests).
5. **Future API paths under the same origin.** The service worker must not cache unknown same-origin paths (Task 6 test).

### Task 2: Lesson reader layout

**Files:** `lib/content/headings.ts`, `lib/content/mdx.ts` (use the plugin), `components/lesson/LessonShell.tsx` (server), `components/lesson/CourseNav.tsx` (server), `components/lesson/Toc.tsx` (server), `components/lesson/ReadingProgress.tsx` (client), `app/[lang]/[roadmap]/[lesson]/page.tsx`, `lib/i18n.ts`, `tests/content/headings.test.ts`, `e2e/lesson.spec.ts`.

**Interfaces:**
```ts
// lib/content/headings.ts
export type Heading = { depth: 2 | 3; text: string; id: string };
export function slugify(text: string): string;            // lowercase, NFKD, letters/digits kept (incl. Kiswahili), spaces→-, trims -
export function extractHeadings(body: string): Heading[]; // ## and ### outside ``` fences, ids de-duplicated (-2, -3)
export function remarkHeadingIds(): (tree: unknown) => void; // same ids, same order, sets data.hProperties.id
```
- Layout: `lg:grid lg:grid-cols-[15rem_minmax(0,1fr)_13rem]` at ≥1100px (Tailwind arbitrary breakpoint `min-[1100px]:`). Sidebars are `sticky top-4 max-h-[calc(100vh-2rem)] overflow-auto`. The article keeps its widths (68ch, or 84ch for labs). Below 1100px, a sticky bar holds two `<details>` menus, "Masomo / Lessons" and "Ukurasa huu / On this page", with no JavaScript.
- `CourseNav`: the roadmap's sections and lessons, with the current lesson marked `aria-current="page"` and ticks from the existing `ProgressTick`.
- `Toc`: the h2s (with h3s nested), then a "next lesson" link.
- `ReadingProgress`: a 3 px bar at the top driven by scroll position on the `<article>`, with `aria-hidden`. Reduced motion means no transition.
